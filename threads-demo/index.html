de execução de um programa.

</> GIL.py print("por que ViaCEP acelera?")

Enquanto espera a internet,
a thread solta o GIL.

  • Outra thread entra e dispara a próxima chamada.
  • Várias chamadas acontecem ao mesmo tempo.
  • O GIL continua ali — ele só não trava quando a thread está esperando.
</> cpu_bound.py print("só CPU, nenhuma espera")

for bloco in blocos:
    checksum = hashlib.sha256(bloco).hexdigest()

Ninguém espera a internet nem o disco. A CPU trabalha o tempo inteiro.

Python 3.13+
sem o GIL.

  • Versão experimental oficial: python3.13t.
  • Mesmo código, mesmas threads — agora usando vários núcleos ao mesmo tempo.
  • Ainda experimental: bibliotecas em C podem quebrar. Essa demo usa só a biblioteca padrão.

sys._is_gil_enabled()  # → False
